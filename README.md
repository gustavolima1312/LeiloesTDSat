# LeiloesTDSat

## 📝 Sobre o Projeto
O **LeiloesTDSat** é um sistema de gerenciamento para casas de leilões desenvolvido como parte de uma atividade prática de versionamento e desenvolvimento Java. 

O objetivo principal da aplicação é permitir o controle de um inventário de produtos, oferecendo funcionalidades essenciais como:
* Cadastro de novos produtos destinados a leilão.
* Listagem e acompanhamento dos itens cadastrados.
* Controle de status de venda (identificando se um produto já foi vendido ou se ainda está disponível).

O projeto foca na organização de dados e na integração entre a linguagem de programação Java e um sistema de gerenciamento de banco de dados (SGBD).

## 🚀 Tecnologias Utilizadas
* **Java**: Linguagem principal utilizada para a lógica de negócio e interface.
* **JDBC / MySQL (ou seu SGBD utilizado)**: Para persistência e armazenamento das informações dos produtos.
* **Git & GitHub**: Ferramentas utilizadas para o versionamento de código e colaboração.
* **Git Bash**: Terminal utilizado para execução dos comandos de versionamento.
